Restore on a new Windows account

py -3.12 restore_skills.py
py -3.12 restore_skills.py --approved

py -3.12 restore_skills.py --plugins
py -3.12 restore_skills.py --plugins --approved

Run from the cloned repository with Git, Python and Codex installed. The default target is your profile's .agents/skills. Use --codex-home PATH to select another profile. The separate harness setup renders local-harness for the actual checkout, bringing the standalone total to 132.

A conflicting skill in either global folder stops publication. The installer never overwrites or deletes existing skills. Plugin restore uses Codex's native installer, preserves enabled plugins and matching registered marketplaces, and reports failures. New Ponytail registration requests a pinned revision; an existing unpinned registration stays as-is.
